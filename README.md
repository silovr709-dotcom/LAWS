# Сайт адвоката Юрия Кочевинова

Персональный сайт адвоката Юрия Анатольевича Кочевинова (Мурманск): уголовно-правовая защита,
представительство потерпевших, работа на стадии проверки, апелляция и кассация.

Сайт построен как **premium editorial**: глубокий бордовый, молочный фон, приглушённое золото,
антиква Cormorant Garamond в заголовках и Golos Text в тексте. Никаких стоковых молотков судьи,
фиктивных кейсов и обещаний результата.

скрипты.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # сборка: dist/client (статика) + dist/server (SSR для /api/contact)
npm start          # запуск собранного SSR-сервера: node ./dist/server/entry.mjs
npm run preview    # предпросмотр собранного сайта
```

Требования: Node.js 20+ (проверено на 22), npm 10+.

Проверка типов (опционально): `npm run check` (требует `@astrojs/check` + `typescript`).

## Как менять контент

### Контакты, тексты, цифры

Почти всё живёт в `src/data/site.ts`. Телефон, почта, VK, адрес, реестровый номер, факты
первого экрана, направления, принципы, биография, порядок работы и FAQ — в одном файле.

> Важно: значения в `site.ts` либо подтверждены открытыми источниками, либо помечены
> «УТОЧНИТЬ». Не добавляйте стаж, награды, должности и проценты успеха без подтверждения.

### Портрет

1. Положите файл `public/images/portrait.jpg` (вертикальный, 4:5, желательно от 1200 px по
   длинной стороне, оптимизированный).
2. Компонент `Portrait.astro` сам обнаружит файл и заменит типографическую плашку с монограммой.
3. Пропорции: первый экран — 4:5, блок «Об адвокате» — 3:4 (обрезка по центру, `object-fit: cover`).

Пока реального фото нет, сайт показывает сдержанную плашку «ЮК»: мы **не подставляем**
изображение другого человека и не генерируем «похожего» адвоката.

### Судебная практика

Коллекция `src/content/cases/` **намеренно пуста** — сайт показывает честный информационный блок
«Каталог практики готовится к публикации», а не вымышленные дела. Пока дел нет, страница
`/praktika/` закрыта от индексации (`noindex`).

Как добавить дело — в `docs/PRACTICE-PUBLISHING.md`. Кратко:

```bash
cp docs/primer-dela.md.txt src/content/cases/moе-delo.md  # шаблон лежит в docs
```

(В docs лежит файл-шаблон `primer-dela.md.txt` — скопируйте и переименуйте в `.md`.)

После добавления первого опубликованного дела (`draft: false`) автоматически:
— появится каталог с фильтрами;
— включатся карточки в блоке «Практика» на главной;
— страница `/praktika/` станет индексируемой;
— дело попадёт в sitemap.

### Публикации

Создайте `.md` в `src/content/articles/`:

```yaml
---
title: 'Заголовок до 120 символов'
description: 'Описание до 300 символов'
publishedAt: 2026-10-19
updatedAt: 2026-10-19
category: 'Уголовный процесс'
readingTime: '7 минут'
sources:
  - label: 'УПК РФ, статья 144'
    url: 'https://www.consultant.ru/document/cons_doc_LAW_34481/'
---
```

Текст — обычный Markdown. Заголовки внутри текста начинаются с `##`. Дата, автор, источники и
дисклеймер подставляются автоматически.

## Форма обращений

`POST /api/contact`:

- проверяет `Content-Type: application/json` и `Origin` (same-origin);
- ограничивает размер тела (8 КБ) и частоту (5 обращений в час с IP);
- honeypot-поле + проверка минимального времени заполнения (1,5 с) против ботов;
- валидирует имя, телефон (10–15 цифр), согласие;
- сохраняет обращение в JSONL: `.data/leads/YYYY-MM-DD.jsonl` (права `0700`/`0600`, вне `public/`);
- при наличии `LEADS_WEBHOOK_URL` отправляет уведомление (Telegram-бот, CRM, n8n и т. п.).

**Что нужно подключить владельцу:**

| Что | Как | Обязательность |
|---|---|---|
| Получение заявок | Прочитать `.data/leads/*.jsonl` или настроить webhook | Обязательно |
| Уведомления в Telegram/CRM | `LEADS_WEBHOOK_URL` (+ `LEADS_WEBHOOK_TOKEN`) | Рекомендуется |
| Почта с сайта | Настроить на стороне почтового сервиса или в webhook | Опционально |
| Аналитика | Не подключена; при подключении — обновить политику и спросить согласие | Опционально |

`.env.example`:

```env
PUBLIC_SITE_URL=https://kochevinov.ru
LEADS_DIR=/var/lib/kochevinov/leads
LEADS_WEBHOOK_URL=
LEADS_WEBHOOK_TOKEN=
CONSENT_VERSION=1.0
```

Обращения **не** содержат и не должны содержать документов и сведений, составляющих
адвокатскую тайну. Форма прямо предупреждает об этом и ограничивает длину сообщения 600 символами.

## Развёртывание

### Вариант A. Node-сервер (нужен для работы формы)

```bash
npm ci
npm run build
HOST=0.0.0.0 PORT=4321 node ./dist/server/entry.mjs
```

Статика отдаётся сервером из `dist/client`, SSR-маршрут `/api/contact` обслуживается Node.
Подойдёт VPS, Docker, Render/Railway и любой хостинг с Node.

> В `output: 'static'` все страницы пререндерятся, SSR включается только для `/api/contact`
> (`export const prerender = false`). Поэтому сайт быстрый, а форма работает.

### Вариант B. Только статика (без формы)

Если форма не нужна, можно разместить `dist/client` на любом CDN (Netlify, Cloudflare Pages,
GitHub Pages). В этом случае:

1. Уберите `adapter` из `astro.config.mjs` **или** оставьте сборку как есть и публикуйте только
   `dist/client` — страницы полностью статические;
2. Замените отправку формы на `mailto:`/телефон или подключите внешний сервис приёма форм;
3. Не забудьте обновить Политику ПД, если меняется модель обработки.

### Nginx (пример)

```nginx
server {
  listen 443 ssl http2;
  server_name kochevinov.ru;

  location / {
    proxy_pass http://127.0.0.1:4321;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Real-IP $remote_addr;   # важно для rate-limit
  }
}
```

HSTS и CSP удобнее добавлять на уровне Nginx. Все остальные security-заголовки уже выставляются
`src/middleware.ts` (`X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`).

## SEO

- Уникальные `title`/`description`, канонические URL, Open Graph и Twitter Card.
- JSON-LD: `Person` (адвокат), `LegalService`, `WebSite`, `FAQPage`, `Article`, `Blog`, `CollectionPage`.
- `sitemap-index.xml` генерируется `@astrojs/sitemap`; `robots.txt` — динамический маршрут.
- ЧПУ: `/praktika/<slug>/`, `/publikacii/<slug>/`.
- Пустая практика и страница согласия закрыты от индексации — чтобы не плодить пустые страницы.
- Домен задаётся через `PUBLIC_SITE_URL` (по умолчанию `https://kochevinov.ru`).

## Доступность и производительность

- Семантические `header`/`nav`/`main`/`section`/`article`, один `h1` на страницу.
- Skip-link, видимый фокус, `aria-expanded` у меню, `aria-live` у формы, `role="status"`.
- Контраст текста проверен для молочного/бордового и графитового/молочного.
- Поддержка `prefers-reduced-motion`: анимации отключаются, контент сразу виден.
- Изображения: `width`/`height`, `loading="lazy"`, `fetchpriority` для первого экрана.
- Нет клиентских фреймворков; JS-бандл — несколько килобайт.
