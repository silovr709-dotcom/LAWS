# Изображения

## portrait.jpg

Положите сюда файл `portrait.jpg` — сайт подхватит его автоматически.

Требования:
- вертикальный кадр, пропорция 4:5 (для первого экрана) и 3:4 (для блока «Об адвокате»);
- от 1200 px по длинной стороне, JPEG, качество 80–85;
- спокойный фон, естественный свет, без агрессивной обработки и фильтров;
- лицо в верхней трети кадра.

Пока файла нет, вместо портрета показывается типографическая плашка с монограммой.
Изображение другого человека или сгенерированный «похожий» адвокат не используются.
