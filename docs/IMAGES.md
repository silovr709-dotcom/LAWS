19.10.2026 владелец прямо поручил использовать три предоставленных фотографии **как образцы
внешности**, а не как фотографии для публикации. 20.10.2026 он подтвердил сходство и попросил
убрать подписи про ИИ, а также добавить больше кадров. Для сайта созданы семь изображений по
этим образцам: два основных портрета и пять кадров галереи на странице «Обо мне».

Эти PNG — новые результаты генерации, не оригинальные фотографии владельца. Образцы внешности
не входят в публичную директорию, `dist/client` или отслеживаемые файлы репозитория. В локальной
работе они находятся только в исключённом кэше; их нельзя переносить в public или коммитить.

Изображения не доказывают присутствие в изображённом помещении, факт съёмки, событие или
должность. Не следует выдавать их за документальные фотографии.

## Воспроизводимая подготовка

```bash
npm ci
npm run portraits
# либо: node scripts/prepare-portraits.mjs /path/to/new-generated-artwork
```

Скрипт использует только указанные сгенерированные PNG. Он не вызывает генератор повторно,
не читает фотографии-референсы и не скачивает изображения.

Результаты:

- герой 4:5, биография 3:4 и пять кадров галереи 4:5, ширины 320, 640, 960, форматы AVIF/WebP;
- отдельная лицевая обрезка 192×192 для аватара (не уменьшенная целиком фигура);
- OG 1200×630: Тверь / Россия, личный портрет, адрес страницы ВКонтакте;
- PNG и самостоятельный SVG OG из одной композиции; названия шрифтов не зависят от системы,
  глифы Cormorant Garamond и Golos Text переведены в контуры через fontkit.

PNG внутри SVG выбран для совместимости рендерера: тест проверяет наличие вариации пикселей
в области портрета, чтобы исчезнувший при растрировании embedded image не прошёл незамеченным.
Сам SVG не содержит внешних URL фотографий или удалённых шрифтов.

## Отображение

`Portrait.astro` использует локальные пути через `withBase`, picture/srcset, размеры,
fetchpriority для первого экрана и lazy-loading для второстепенных изображений. Размеры
загрузки для полноразмерной биографии задаются отдельно от её небольшой версии на главной.
Подписи про ИИ удалены по просьбе владельца; alt описывают человека и кадр, а не способ
создания. На странице «Обо мне» прямо сказано, что изображения постановочные и не являются
документальной съёмкой конкретного события: убирая пометку, нельзя создавать ложное
впечатление о факте съёмки. Референсы не используются как запасная фотография.

При замене исходника проверьте лицо и обрезку аватара отдельно, запустите `npm test` и
браузерные проверки. Сходство и правомерность использования не устанавливаются автоматическим
тестом: это отдельное подтверждение владельца.
