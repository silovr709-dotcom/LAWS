# Проверки

## Обязательные, без браузера

```bash
npm ci
npm run check
npm test
npm run build
npm run check:build
```

`npm test` использует node:test + tsx: отключение API по умолчанию, приватный каталог,
origin/type/size, некорректный JSON, consent/version, антиспам, лимит, запись и ошибки диска,
HTTP и сетевые ошибки webhook, содержательность направлений и оптимизированные изображения.
Тесты не отправляют реальные обращения или уведомления; временные файлы создаются в `.cache`.

`check:build` читает готовый dist/client: один h1, уникальные title, description, canonical/OG,
внутренние ссылки/якоря, ресурсы, manifest, JSON-LD, sitemap, noindex и реальный контактный режим.
Для других конфигураций передайте ожидания:

```bash
EXPECT_SITE=https://silovr709-dotcom.github.io EXPECT_BASE=/LAWS \
  EXPECT_NOINDEX=true npm run check:build
# Для явно включённой серверной формы дополнительно EXPECT_FORM=server.
# Для утверждённого индексируемого запуска EXPECT_NOINDEX=false.
```

Пустая коллекция дел даёт предупреждения Astro. Не добавляйте вымышленное дело ради тишины
в логе. После первого реального опубликованного дела проверки учитывают появившийся каталог.

## Браузерный прогон (опциональные инструменты отдельно)

Для Linux-песочницы, без увеличения зависимостей приложения на Chromium:

```bash
npm install --prefix .cache/audit-tools --no-save \
  playwright-core @sparticuz/chromium axe-core
npm run dev
# В другом процессе:
npm run test:browser
```

Нужен работающий сайт на 0.0.0.0:4321. Инструмент использует локальный адрес **изнутри
песочницы**; пользователь открывает Live Preview, не localhost своего компьютера.
Для готовой Pages-сборки, запущенной Node на другом тестовом порту:

```bash
AUDIT_URL=http://127.0.0.1:4322 AUDIT_BASE=/LAWS \
  AUDIT_OUT=.cache/premium-audit/pages npm run test:browser
```

Можно задать `AUDIT_TOOLS_DIR` или `BROWSER_EXECUTABLE` для уже установленного браузера.
Кэш, браузер, PNG-снимки и JSON-отчёты не входят в Git. Скрипт проверяет страницы на 320/1440,
главную также на 390/768/1025, отсутствие переполнения, ошибок JS, самопроизвольных внешних
запросов и browser storage; axe WCAG A/AA + best practices, меню, фокус, Escape, скролл,
анкоры, прямой контакт, локальные цели, no-JS и отказ загрузки модулей.

## Необязательная форма

Соберите и запустите отдельный **локальный** тестовый Node-стенд с `/LAWS` и opt-in из DEPLOY.md.
Не подключайте реальный webhook. Не используйте сервер, принимающий реальные обращения.

```bash
FORM_AUDIT_URL=http://127.0.0.1:4322/LAWS/ npm run test:form-browser
```

Тест перехватывает все POST и не передаёт введённые тестовые значения в API. Проверяет
320/390/1440, нативный checkbox 20×20, клавиатуру, валидацию, ошибки сети/HTTP/JSON,
сохранение текста, блокировку дубля, фокус успеха, событие без PII и безопасное поведение
без JavaScript. Настоящая цепочка API → закрытый JSONL проверяется отдельно только на
вымышленных тестовых данных. Доставка реальному оператору — отдельный приёмочный тест.

## Границы результата

Автоматический успех не подтверждает сходство лица, актуальность юридического текста,
доступность на всех устройствах или рост конверсии. Нет Lighthouse/полевых измерений и
подключённой аналитики. Перед выпуском нужны ручное ревью владельца и проверка реального
размещения, домена, контактов и модели обработки.
