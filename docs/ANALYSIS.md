# Доработка по аудиту — 19.10.2026

**Состояние: локальная реализация и тестовое превью. Нового push, PR или деплоя не было.**
Публичная Pages-версия не обновлена этой доработкой. Итоговые изображения и тексты ещё должен
утвердить владелец; это не сертификат юридического соответствия или доступности.

## Что изменено

1. По трём фотографиям-образцам внешности созданы два новых ИИ-портрета. Оригинальные фотографии
   не опубликованы. Портреты, аватар и OG внедрены с честными обозначениями; generated sources
   сохранены отдельно, изображения оптимизированы в AVIF/WebP. Сходство требует утверждения.
2. Вместо анкеты, которая только открывала VK для повторного ввода, — прямая ссылка без сбора
   имени/телефона/сообщения сайтом. Реальная форма включается отдельно, только с Node API,
   opt-in и каталогом хранения. Ошибки не превращаются в фиктивный успех.
3. Пустой блок практики и ссылка на пустой каталог убраны с главной и навигации. Не создано ни
   одного вымышленного дела; каталог по прямому URL остаётся noindex. Draft по умолчанию не
   считается опубликованным делом, включая проверку для sitemap.
4. Главная сокращена: биография и подробная география вынесены на `/ob-advokate/`, направления
   ведут на шесть отдельных страниц. Добавлена страница помощи близкому, связанные статьи и
   понятный порядок первого контакта/согласования условий. Цены и бесплатность не выдуманы.
5. Исправлены переполнение 320 px (в том числе длинные слова/перенос ФИО), меню и фокус,
   нативный checkbox, подписи и контраст. Содержимое не скрывается при no-JS или отказе модуля.
6. Canonical, JSON-LD и ссылки согласованы с базовым путём — не только в статье, но и в
   каталогах. Manifest и OG больше не используют Мурманск как город оказания услуг.
7. По умолчанию noindex, Pages остаётся noindex даже при ошибочном явном разрешении.
   Аналитика не подключена: есть только локальные PII-free события без отправителя/хранения.
   Документы и `.env.example` согласованы с текущей моделью; нет неподтверждённых заверений
   о локализации всех журналов/переписки или гарантированной доставке уведомлений.

## Локальное сравнение главной

Измерено Chromium на одинаковых ширинах, после загрузки шрифтов. Высота страницы — не метрика
конверсии и не Lighthouse. Исходные снимки/метрики получены до переработки; финальные — из
готовой сборки для `/LAWS`, обслуживаемой Node без включённой формы.

| Метрика | До | После |
|---|---:|---:|
| Высота страницы, 1440×1000 | 11 311 px | 6 332 px |
| Высота страницы, 390×844 | 17 538 px | 8 889 px |
| Условных экранов на 390×844 | 20,8 | 10,5 |
| Высота героя на 390×844 | 1 321 px | 731 px |
| Переполнение на 320 px | scrollWidth 372 при clientWidth 320 | 320 / 320 |
| Основной CTA на 320×568 | Перегруженная композиция | y=425…475, выше нижней панели |

Главная примерно на 49% короче на телефоне и на 44% на широком экране. Вёрстка 320 не
масштабируется из-за горизонтального переполнения, так что сравнение её старой высоты
не используется как честная метрика сокращения.

## Что остаётся решением владельца

- сходство, возраст и использование обоих ИИ-портретов;
- личные телефон/email, адрес приёма, точный формат консультации, платность и условия оплаты;
- актуальность специализаций, текстов статей и юридических документов;
- реальные дела с подтверждением участия и основанием публикации;
- подтверждённый домен, хостинг и разрешение индексации;
- выбор прямого контакта либо организационно готового собственного приёма данных;
- отдельное решение по аналитике, если она понадобится.

Без этих подтверждений нельзя обещать экстренный ответ, называть цены, публиковать дела или
считать форму производственно готовой. Измерений реальной посещаемости и конверсии нет.
