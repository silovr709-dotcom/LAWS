# Публикация судебной практики: правила и шаблон

## Почему коллекция пуста

Каталог практики **намеренно пуст**, пока нет материалов, прошедших проверку. На главной нет пустого блока, в навигации нет ссылки на пустой каталог. Сам `/praktika/` доступен по прямому адресу с честным пояснением, закрыт от индексации и отсутствует в sitemap. Вымышленные или автоматически подобранные дела не публикуются.

## Три обязательных условия

### 1. Подтверждение участия

Дело публикуется, только если участие адвоката подтверждено процессуальным документом:
ордер, соглашение, протокол, судебный акт с указанием защитника/представителя.

Совпадения фамилии в картотеке **недостаточно**: однофамильцев много, а автоматический импорт
по фамилии — прямой путь к ложной информации в рекламе юридических услуг.

### 2. Допустимость публикации

Учитывайте:

- **адвокатскую тайну** (ст. 8 ФЗ-63): сведения, связанные с оказанием юридической помощи,
  не раскрываются без согласия доверителя;
- **персональные данные** участников: имена, адреса, даты рождения, номера дел, сведения о
  здоровье и семейной жизни удаляются или обезличиваются;
- **ограничения по уголовным делам**: не публикуйте сведения о несовершеннолетних, потерпевших
  по делам о преступлениях против половой неприкосновенности, данные, позволяющие установить
  личность, а также материалы, не вступившие в законную силу, если это может повлиять на
  судопроизводство;
- **согласие доверителя** — желательно письменное, даже если текст обезличен;
- **требования к рекламе** (ФЗ-38) и правила адвокатской этики: без обещаний результата,
  сравнений с другими адвокатами и «процентов успеха».

Обезличивание считается достаточным, если по совокупности сведений нельзя определить
конкретное лицо или конкретное дело без дополнительной информации.

### 3. Правовое основание

В карточке поле `publicationBasis` заполняется обязательно. Примеры формулировок:

- «Судебный акт опубликован в открытом доступе; сведения обезличены, согласие доверителя
  получено».
- «Согласие доверителя от 12.03.2026; имена и идентифицирующие сведения исключены».
- «Дело рассмотрено в открытом судебном заседании; персональные данные участников удалены».

## Шаблон

Скопируйте `primer-dela.md.txt` в `src/content/cases/<slug>.md`. Имя файла = URL:
`src/content/cases/ekonomicheskoe-delo.md` → `/praktika/ekonomicheskoe-delo/`.

```yaml
---
title: 'Прекращение уголовного дела на стадии проверки'
category: 'Экономические преступления'
court: 'Следственное управление УМВД России по субъекту РФ'
instance: 'первая инстанция'      # первая инстанция | апелляция | кассация
year: 2025
role: 'защитник'                  # защитник | представитель потерпевшего
result: 'прекращение дела'        # см. перечень ниже
summary: 'Краткое описание сути дела без идентифицирующих сведений, 1–3 предложения.'
legalIssue: 'Правовой вопрос: что оценивалось, какая норма применялась, в чём была коллизия.'
actions:
  - 'Изучены материалы проверки'
  - 'Подготовлены объяснения и ходатайство'
outcome: 'Итог в пределах подтверждённых материалов, без оценки «выиграли/проиграли».'
sourceUrl: 'https://sudact.ru/...' # если акт есть в открытом доступе
sourceLabel: 'Судебный акт на Sudact'
publicationBasis: 'Согласие доверителя от 01.09.2025; сведения обезличены.'
anonymized: true                   # обязательно true
publishedAt: 2026-10-01
draft: false                       # false = публикуется
---
```

Допустимые значения `result`:

`оправдание`, `прекращение дела`, `переквалификация`, `смягчение наказания`,
`судебный акт оставлен без изменения`, `судебный акт отменён`, `иное`.

## Что происходит после добавления

1. Дело появляется в `/praktika/`, в блоке практики на главной (последние два); включается пункт навигации «Практика».
2. Включаются фильтры по категории, инстанции и результату (если значений больше одного).
3. Дело попадает в sitemap и JSON-LD `ItemList`. Индексация разрешается только после общего запуска с `PUBLIC_NOINDEX=false`; временный Pages остаётся noindex.
4. `draft: true` — дело видно только в исходниках, не на сайте.

## Редакционный чек-лист

- [ ] Участие подтверждено процессуальным документом.
- [ ] Нет имён, адресов, номеров дел и иных идентификаторов.
- [ ] Нет сведений, составляющих адвокатскую тайну.
- [ ] Есть основание публикации.
- [ ] Формулировки не обещают результат и не создают ложного впечатления о вероятности успеха.
- [ ] Ссылка на первоисточник работает (или поле не заполнено).
- [ ] Текст проверен адвокатом лично.
